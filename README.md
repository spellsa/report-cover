# レポート表紙

電子情報工学実験レポートの表紙です。完成例は `report_cover_sample.pdf` を見てください。

## 使い方

普段使っているレポートの `.tex` ファイルと同じフォルダに、`report_cover.tex` を置きます。

```text
レポートのフォルダ/
├── main.tex          ← 普段使っているレポートのファイル
└── report_cover.tex  ← 表紙を作るためのファイル
```

`main.tex` に、`report_cover_sample.tex` を参考に必要なパッケージと以下の設定を追加します。
